# メカアシュラ君 — 奥義カスタマイズ工房

<p align="center"><img src="images/mecha-ashura-card.png" width="720" alt="メカアシュラ君"></p>

**ZIPを放り込んで話しかけるだけ。解凍も、起動も、あなた専用の改造も、ぜんぶメカアシュラ君がやります。**

「奥義をダウンロードしたけど、そこから先がわからない」——そんな人のための奥義です。

## 使い方（3ステップ）

1. **このフォルダに、改造したい奥義のZIPを放り込む**
   - 奥義は [アシュラのサイト](https://service.if-juku.net/Ashura/arts) の「ダウンロード（ZIP）」から
   - ZIPのままでOK。解凍しなくていいです
2. **このフォルダを Claude Code（または Codex）のアプリで開く**
   - アプリの「フォルダを開く」→ デスクトップ → `MechaAshura` を選ぶ
3. **チャットで「起動して」と話しかける**
   - メカアシュラ君が「何を改造したいんじゃ？」と聞いてくるので、あとは会話するだけ

## メカアシュラ君がやってくれること

| あなたがすること | メカアシュラ君がすること |
|---|---|
| ZIPを放り込む | 解凍して中身を調べ、何の奥義か説明 |
| 「起動して」と言う | インストールと起動、エラーが出ても自分で修理 |
| 仕事の話をする | あなたの仕事に合わせた改造案を3つ提案 |
| 改造を選ぶ | 実装→再起動→動作確認まで一括対応 |

## 2個目からはもっと速い（工房カルテ）

最初のヒアリングであなたの仕事・ブランドの情報が `工房カルテ.md` に記録されます。2個目以降の奥義では聞き直されず、いきなり「あなた仕様」の改造案が出てきます。

また、改造の内容は各奥義フォルダの `改造記録.md` に残るので、奥義を最新版に更新して改造が消えても、記録をもとに同じ改造をやり直してもらえます（「本家を更新して、改造も戻して」でOK）。

## つまずいたら（心得）

- **エラーが出た** → 赤い文字をそのままチャットに貼って「直して」。それで直ります
- **許可を聞かれた** → 「常に許可」を選ぶと、毎回聞かれなくなります
- **なんか変** → Claude Code / Codex アプリが古いと不調のもと。まずアプリを最新にしましょう

> どの奥義も「フォルダを開く → チャットで起動 → チャットで修正」の型は同じ。
> この型さえ覚えれば、あら不思議、奥義があなたのものになります。

## インストール（1行コマンド派の人向け）

Mac（ターミナルに貼り付け）:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Getabako/MechaAshura/main/install.sh)"
```

Windows（PowerShellに貼り付け）:

```powershell
iwr -useb https://raw.githubusercontent.com/Getabako/MechaAshura/main/install.ps1 | iex
```

デスクトップに `MechaAshura` フォルダができます。あとは上の3ステップの2番から。
